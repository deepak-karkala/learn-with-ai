# API Design Module Content

## Content Structure

This module contains:

- `tutorial.md` - The comprehensive API design tutorial content (✅ Available)
- `video.mp4` - Video lesson explaining API design concepts (📹 To be added)
- `audio.mp3` - Audio narration of the API design lesson (🎵 To be added)

## Adding Video and Audio Content

To add video and audio content for this module:

1. **For Video Content:**
   - Add a video file named `video.mp4` (or `video.webm`, `video.mov`, etc.)
   - Supported formats: MP4, WebM, MOV, AVI
   - Recommended: MP4 format for best compatibility

2. **For Audio Content:**
   - Add an audio file named `audio.mp3` (or `audio.wav`, `audio.ogg`, etc.)
   - Supported formats: MP3, WAV, OGG, M4A
   - Recommended: MP3 format for best compatibility

## File Naming Convention

The learning interface will automatically detect files with these naming patterns:
- Video: `video.*` (any supported video extension)
- Audio: `audio.*` (any supported audio extension)

Once you add the media files, they will automatically appear in the learning interface with fully functional players including:

### Video Player Features:
- Play/Pause controls
- Seek bar with time display
- Volume controls with mute
- Playback speed control (0.5x to 2x)
- Skip forward/backward (10 seconds)
- Fullscreen mode
- Responsive design

### Audio Player Features:
- Play/Pause controls
- Seek bar with time display
- Volume controls with mute
- Playback speed control (0.5x to 2x)
- Skip forward/backward (10 seconds)
- Restart function
- Beautiful card-based UI
